Security Automation with Python
Overview

This repository contains Python-based security automation tools designed to improve Security Operations Center (SOC) efficiency and investigative speed.

The objective is to demonstrate practical skills in:

Log parsing and normalization

Indicator of Compromise (IOC) enrichment

Alert data processing

Workflow automation for analysts

These tools reflect real-world SOC engineering practices used to reduce manual effort and accelerate incident response.

Automation Goals

Reduce repetitive analyst tasks

Improve speed of threat investigation

Standardize security data processing

Support detection and incident response workflows

Demonstrate Python scripting in cybersecurity contexts

Planned Automation Tools

This repository will include scripts such as:

Log Parser

Extract security-relevant fields from raw logs

Normalize timestamps and event data

Prepare logs for SIEM ingestion or analysis

IOC Enrichment Tool

Accept IP addresses, domains, or file hashes

Query threat intelligence sources

Return risk context for analysts

Alert Summary Generator

Convert raw alert data into readable investigation notes

Highlight severity, timeline, and affected assets

File Hash Scanner

Compare file hashes against known malicious indicators

Assist malware triage workflows

Skills Demonstrated

Python scripting for cybersecurity

Security data parsing and transformation

Threat intelligence integration concepts

SOC workflow optimization

Automation-driven incident response support

Future Enhancements

Planned improvements include:

Integration with SIEM APIs
